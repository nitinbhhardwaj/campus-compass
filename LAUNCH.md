# Launch Checklist

Before launching Campus Compass, verify and complete all items below:

- [ ] custom domain connected with HTTPS
- [ ] favicon showing in browser tab and phone home screen
- [ ] no AI tags (npm run check passes)
- [ ] privacy and terms pages live and linked
- [ ] contact email set and working
- [ ] tested at 390, 768, 1280 and 1920 px
- [ ] tested in Chrome, Safari and Firefox
- [ ] keyboard-only walkthrough
- [ ] Lighthouse accessibility score checked
- [ ] no console errors
- [ ] 404 page
- [ ] README has no invented numbers
