# Project Rules

These rules are permanent. Follow them in every future task.

1. Color and Styling Restrictions:
   - No purple or violet colors.
   - No gradient backgrounds, no Tailwind bg-gradient or from-, via-, to- utilities.
   - The only allowed CSS gradients are the graph paper grid and the hatched budget bar defined in the theme file (src/index.css).
   - No pill-shaped controls. Buttons, chips and toggles use a 4px radius. No rounded-full on buttons or chips.

2. Content and Typography:
   - No emoji anywhere: UI, copy, docs, commit messages, README. Icons are SVG (Lucide is fine).
   - No em dashes or en dashes in any copy, docs or UI text. Use commas, periods or colons.
   - No fake reviews, testimonials, user counts, statistics, logos, customer names or contact details. Sample data is allowed only inside clearly marked tests and docs mockups.
   - No vague hero text. Headlines state something specific and true that comes from real data.
   - Copy is plain, specific and written for the student using the app.

3. Media and Motion:
   - No AI-generated photos or stock imagery. No decorative imagery at all.
   - No scroll-triggered animations, parallax, cursor effects or entrance animations.
   - Motion is limited to responses to user actions (open, close, confirm), 150ms or less, and respects prefers-reduced-motion.

4. Attribution and Tagging:
   - No "Made with AI", "Built with", "Generated by", Antigravity, Claude, Gemini or similar tags, comments, badges or meta tags in any shipped file.
